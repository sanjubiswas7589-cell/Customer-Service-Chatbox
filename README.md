# Customer Service Chatbot

## Overview

A rule-based chatbot built in Python that answers common customer service queries.

## Features

- Greeting users
- Business hours
- Contact information
- Delivery details
- Refund policy
- Return policy
- Payment methods
- Order tracking
- Order cancellation
- Store location
- Help menu

## Technologies Used

- Python 3
- Rule-Based NLP
- Keyword Matching
- Regular Expressions

## How to Run

Clone the repository:

```bash
git clone https://github.com/YourUsername/Customer-Service-Chatbot.git
```

Navigate to the project:

```bash
cd Customer-Service-Chatbot
```

Run the chatbot:

```bash
python chatbot.py
```

## Example Questions

- Hello
- What are your working hours?
- How can I return a product?
- Refund
- Delivery
- Contact support
- Payment methods
- Track my order
- Cancel my order
- Bye
